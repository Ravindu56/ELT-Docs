# ELT-Docs

Match summary poster generator for the Prof. A. Thurairajah Memorial Cricket Tournament 2K26 (E-Legends Trophy).

## Files
- `match-summary.html` - single-file poster generator (all 4 matches included, dropdown to switch, PNG/PDF export)
- `images/` - logos used by the poster (add these locally):
  - `tournamentLogo.png` (transparent PNG)
  - `E22.png`, `E23.jpg`, `E24.jpg`, `E25.jpg`

## Usage
Open `match-summary.html` in Chrome, pick a match, then use **Download PNG** or **Save as PDF**.
Edit the `matches` array inside the script to add or change match data.
